An audio server for Discord bots.

> [!WARNING]
> The API is experimental and may change without notice, including breaking changes.

## Features

- Audio playback from HTTP and HTTPS URLs.
- Per-guild queues with pause, resume, skip, and automatic track advancement.
- HTTP API with real-time player and track events over SSE.
- TypeScript SDK with discord.js integration.
